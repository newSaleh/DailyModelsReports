# محلل مبيعات الموديلات (Daily Models Reports)

تطبيق ويب بسيط (HTML/CSS/JS بدون أي خطوة بناء) لتحليل مبيعات الموديلات من ملف
Excel أو من نص ملصوق، وإنشاء تقريرين جاهزين للنسخ مباشرة إلى واتساب/تيليجرام:

1. أكثر 20 موديل بيعًا حسب الكمية.
2. أكثر 20 موديل بيعًا حسب مبلغ البيع.

## التشغيل

لا يحتاج التطبيق أي تثبيت أو اتصال إنترنت (مكتبة قراءة Excel مضمّنة محليًا في
`js/vendor/xlsx.full.min.js`). يكفي فتح `index.html` مباشرة في المتصفح، أو
تشغيله عبر أي خادم ملفات ثابت بسيط، مثلًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## المفتاح الأساسي للتجميع

يتم تجميع كل السجلات التي تحمل نفس **ModelCode** كموديل واحد، بغض النظر عن
اختلاف رقم المورد (SupplierCode) أو اسمه. يتم جمع الكمية ومبلغ البيع ومبيعات
كل فرع بعد الدمج. أي تعارضات في اسم الموديل، أو السعر، أو تعدد الموردين لنفس
الموديل تظهر في قسم "ملاحظات على البيانات" أسفل التقرير دون اختراع بيانات أو
اختيار قيمة عشوائيًا.

## الفروع

ترتيب الفروع ثابت دائمًا: الدائري، التحلية، البديعة، الفيحاء، القصيم. أي فرع
بدون مبيعات لموديل معيّن يظهر باسم "غير موجود" بدل الرقم صفر.

للتعديل على قائمة الفروع أو أسماء الأعمدة المتعرَّف عليها لاحقًا، عدّل ملف
`js/config.js` فقط.

## بنية الكود

- `js/config.js` — إعدادات الفروع وأسماء الأعمدة المتعرَّف عليها (عربي/إنجليزي).
- `js/utils.js` — دوال مساعدة (تحويل أرقام، تنسيق، تواريخ، مطابقة عناوين).
- `js/parser.js` — تحويل ملف Excel أو نص ملصوق إلى صفوف بيانات، ومطابقة الأعمدة.
- `js/aggregator.js` — التحقق من البيانات، الدمج حسب ModelCode، وبناء ملاحظات الجودة.
- `js/report.js` — بناء نص التقريرين بالشكل الجاهز للنسخ.
- `js/app.js` — ربط الواجهة (رفع الملف، اللصق، التاريخ، النسخ).
- `js/vendor/xlsx.full.min.js` — مكتبة [SheetJS](https://sheetjs.com) (رخصة Apache-2.0) لقراءة ملفات Excel، مضمّنة محليًا.

## صيغ البيانات المدعومة

- **صيغة عريضة (Wide)**: عمود لكل فرع، كما في تقرير TopModels (مثال: `701SoldQty`،
  `706SoldQty`...)، مع عمود `UnitPrice`. مبلغ البيع يُحسب تلقائيًا (الكمية × السعر)
  إن لم يوجد عمود مبلغ بيع صريح.
- **صيغة طويلة (Pivot)**: عمود "الفرع" + عمود "الكمية"، سطر لكل فرع.
- **بدون بيانات فروع**: يتم احتساب الإجمالي فقط، وتظهر كل الفروع "غير موجود" مع
  ملاحظة توضح ذلك.

## التاريخ

إذا احتوت البيانات على عمود تاريخ، يتم تصفية السجلات حسب التاريخ المختار
فعليًا. إن لم يوجد عمود تاريخ (كما هو الحال في ملفات التصدير اليومية التي لا
تحمل تاريخًا داخل كل سطر)، يُستخدم التاريخ المختار كتسمية للتقرير فقط، ويُحلَّل
كامل الملف/النص المدخل.
